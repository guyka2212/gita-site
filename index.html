Install

One-command setup

Install Gita anywhere with a single curl pipe. No package manager required.

Terminal
curl -sSL "https://raw.githubusercontent.com/guyka2212/gita/main/install.sh" | bash

After installation, open a fresh terminal and run gita to verify.

Step 1

Creates ~/.gita/{scripts,templates,pushes}

Step 2

Writes inline documentation manifests

Step 3

Downloads engine to /usr/local/bin/gita

Step 4

Installs rich Python library (if pip available)

Structure

How it's organized

Everything lives under ~/.gita/ — a single directory you can back up, sync, or version-control.

~/.gita/ # Storage hub
├── pushes/ # Project snapshots via `gita push`
├── templates/ # Starter blueprints via `gita -t`
└── scripts/ # Custom automations via `gita run`
Concepts

What you can do

Three core features that work together to make your projects portable and reproducible.

📸

Project Snapshots

Full working-tree copies saved with gita push. Restore them anywhere with gita pull.

gita push my-app-v2
🧩

Starter Templates

Framework skeletons (npm_app, python_app, etc.). Apply one into the current directory instantly.

gita -t npm_app
⚡

Custom Automations

Executable scripts you invoke from any directory. No path hunting — just gita run.

gita run deploy
Commands

CLI reference

Every command at a glance.

Action Command Description
Save state gita push <name> Copy current directory into ~/.gita/pushes/<name>
Restore state gita pull <folder>/<name> Extract a saved push into a new subdirectory
Apply template gita -t <name> Copy a starter blueprint into the current folder
List templates gita -t -ls Show all available templates
Run automation gita run <name> Execute a script from ~/.gita/scripts/

gita push <name>

Backs up the entire current working directory (excluding .git and .gita) into ~/.gita/pushes/<name>/.

cd ~/projects/my-app
gita push my-app-v2
# Saved in ~/.gita/pushes/my-app-v2/

gita pull <dest-folder>/<name>

Reconstructs a previously saved snapshot as a new directory under the current working tree.

gita pull restored-app/my-app-v2
# Creates ./restored-app/ from ~/.gita/pushes/my-app-v2/

gita -t <template-name>

Injects a template from ~/.gita/templates/<template-name>/ into the current directory.

mkdir my-new-project && cd my-new-project
gita -t npm_app
# package.json, index.js, etc. are now present

gita -t -ls

Lists every subdirectory inside ~/.gita/templates/.

gita -t -ls
# Available Gita Templates:
#   • npm_app
#   • python_app

gita run <script-name>

Safely executes ~/.gita/scripts/<script-name> via bash. Scripts must be executable and contain a valid shebang.

gita run sys-check
# Runs: bash ~/.gita/scripts/sys-check
Extending

Add your own

Gita is designed to grow with you. Add templates and scripts whenever you need them.

📦 Adding a Template

Create a directory under ~/.gita/templates/, populate it, and use it instantly.

mkdir -p ~/.gita/templates/react-app
# populate with package.json, src/, etc.
gita -t react-app

⚙️ Adding a Script

Drop an executable script into ~/.gita/scripts/ and run it from anywhere.

touch ~/.gita/scripts/deploy
chmod +x ~/.gita/scripts/deploy
# First line: #!/bin/bash
gita run deploy
Plugins

Plugin developer guide

Because the Gita engine uses an extensionless runner system, you can easily build, install, and share plugins using Bash, Python, or any scripting language.

📥 How to install plugins

Method A: Automated installer

If your Gita configuration includes install-plugin, install any remote script instantly from a raw URL:

gita install-plugin https://raw.githubusercontent.com/username/repo/main/my-plugin my-plugin

Method B: Manual installation

Drop a script directly into your scripts directory:

touch ~/.gita/scripts/my-plugin
# Open in an editor, paste your code, then:
chmod +x ~/.gita/scripts/my-plugin

🛠️ How to create plugins

Writing a plugin is just writing a script — no extension, a valid shebang, and executable permissions.

Example A: Bash plugin

Save as ~/.gita/scripts/workspace-lock:

#!/bin/bash

if [ -z "$1" ]; then
    echo "Error: Missing snapshot name."
    echo "Usage: gita run workspace-lock [snapshot-name]"
    exit 1
fi

echo "Freezing directory state..."
gita push "$1"

echo "Locking down project files to read-only..."
chmod 444 *
echo "Finished protecting workspace state."

Example B: Python plugin

Save as ~/.gita/scripts/system-stat:

#!/usr/bin/env python3
import sys
import shutil

if len(sys.argv) > 1 and sys.argv[1] == "--help":
    print("Usage: gita run system-stat")
    sys.exit(0)

total, used, free = shutil.disk_usage("/")
free_gb = free // (2**30)

print("Gita Local Infrastructure Report")
print(f"Storage Remaining: {free_gb} GB Available")

🚀 How to publish & share plugins

Step 1

Create a public GitHub repo (e.g. gita-plugins) and add your extensionless script files.

Step 2

Open your script file on GitHub, click the "Raw" button, and copy the URL.

Step 3

Share the raw link. Users install with:
gita install-plugin <raw-url> <name>
